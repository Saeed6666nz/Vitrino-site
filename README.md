

# Vitrino | ویترینو

نسخه نمایشی استاتیک فروشگاه ویترینو (فارسی، راست‌چین و سازگار با موبایل).

## وضعیت
- صفحه اصلی و جست‌وجوی محصولات نمونه
- فیلتر دسته‌بندی
- سبد خرید آزمایشی در سمت کاربر
- بدون بک‌اند، پرداخت، سفارش واقعی یا موجودی تأییدشده

## انتشار
مخزن از GitHub Actions برای انتشار GitHub Pages استفاده می‌کند. پس از اولین اجرای workflow، در صورت درخواست GitHub، بخش Settings → Pages را روی **GitHub Actions** تنظیم کنید.
